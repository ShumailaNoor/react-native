# Today's Learning Summary

Today, I focused on **React fundamentals** with hands-on practice. The main concepts covered were:

---

## Key Concepts Learned

1. **Props**

   * Passing data from parent to child components.
   * Rendering dynamic values using props.
   * Example: Passing a name and email to display below a form.

2. **useState Hook**

   * Managing state in functional components.
   * Used for updating UI dynamically on user interactions.
   * Example: Changing background color on button click.

3. **Event Handling**

   * Handling user actions like button clicks and form submissions.
   * Updating state based on events.

---

## Practice Exercises

* **Practice 1:** Created a component to display props (e.g., `name`, `age`).
* **Practice 2:** Built a form with inputs (`name`, `email`) and displayed values below using props.
* **Practice 3:** Implemented a button that changes background color on click using `useState` + event handling.
* **Practice 4:** Passed an array of items as props and rendered them in a list.

---

##️ Mini Project: To-Do List App

A small React project combining all three concepts:

* **Input field + Add button** → Add new tasks.
* **List rendering with props** → Display tasks in a separate component.
* **Mark completed tasks** → Strike-through effect on click.
* **Delete tasks** → Remove task with a delete button.

This project reinforced:

* **useState** for managing task list.
* **Props** for passing tasks & functions between components.
* **Event Handling** for adding, deleting, and marking tasks.
