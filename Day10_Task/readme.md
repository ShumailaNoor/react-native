# Day 10 – Arrays and Student Grade Dashboard

## What I Learned Today

Today, I focused on understanding JavaScript arrays and their powerful methods. Arrays are essential for storing and working with collections of data, and I practiced both the basics and some higher-order functions.

### Key Topics
- What an array is, and how to declare and initialize it.
- Accessing elements using indexing and checking the length of an array.
- Common array methods:
  - `push`, `pop`, `shift`, `unshift`
  - `splice`, `slice`
  - `indexOf`, `includes`, `find`, `findIndex`
- The difference between mutable operations (that change the original array) and immutable operations (that return a new array).
- Higher-order functions and their use cases:
  - `map()` – transforms elements and returns a new array.
  - `filter()` – selects elements based on a condition.
  - `reduce()` – accumulates values into a single result.

### Mini Project – Student Grade Dashboard
I built a small project to tie everything together.  
The Student Grade Dashboard manages a list of students and their marks.  

Features:
- Calculate each student’s average grade using `map` and `reduce`.
- Filter students who scored above an average of 80.
- Compute the class average.
- Sort students by their average grades.
- Add new students with `push()`.
