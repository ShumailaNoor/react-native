# JavaScript Learning Summary - Destructuring & Template Literals

## Concepts Learned

### Destructuring
- **Array Destructuring**: Extract values from arrays into variables.
- **Object Destructuring**: Extract properties from objects into variables.
- **Nested Destructuring**: Access values inside nested objects/arrays.
- **Default Values**: Assign fallback values when properties or array elements are missing.
- **Function Parameter Destructuring**: Simplify function arguments by unpacking values directly.

### Template Literals
- **Backtick (`) Syntax**: Alternative to single/double quotes.
- **String Interpolation**: Insert variables and expressions using `${}`.
- **Multi-line Strings**: Create strings spanning multiple lines easily.
- **Expression Evaluation**: Run JavaScript expressions directly inside strings.
